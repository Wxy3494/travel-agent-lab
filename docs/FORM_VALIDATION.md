# 表单错误提示

首页提交时逐项检查输入，具体原因显示在对应输入框正下方，同时标红该输入框。按钮附近仅提示需要调整的字段数量，不再在页面底部罗列所有可能的错误。

- 缺少必填项：只标记空白项。
- 天数不足：在旅行天数下显示目的地数量与最少天数。
- 必去与排除冲突：两栏同时说明冲突地点。
- 房间数超过人数：在房间数下说明实际人数和房间数；人数明确为“出行总人数（含本人）”。两人两间房可以正常提交。
- 时间颠倒、跨午夜或被清空：对应时间框说明问题。09:00～21:30 为有效默认值。
- 住宿地址格式、城市或长度不合要求：在住宿地址下说明问题。

首次提交前不展示空白必填项错误。提交后编辑相关字段并移开焦点，错误随校验结果更新；修正一处不会清空其他内容。有错误的可选项在再次提交时自动展开。修改输入不会自动生成行程或调用付费规划接口；只有点击生成按钮才提交规划。

从历史行程改短天数或更换目的地时，原来按天指定的景点需重新安排，页面在天数下说明这一变化；保留当前必去地点，历史版本不变。避免不可见的旧“第4天”设置拦截合法的两日表单。界面使用受控展开面板，依赖 Streamlit 1.65 及以上；现有锁定环境为1.65.0，无须更新当前环境。

保存状态与当前程序不兼容时，在表单顶部明确提示重新开始或读取历史，不把程序状态错误归咎于某个输入。用户截图没有显示全部字段，无法仅凭截图确定当时具体哪一项导致了旧提示。

验证包括纯校验边界、Streamlit AppTest，以及安装在本机的 Chrome 真实交互：逐项显示、修正清除、输入框红边、收起后提交自动展开、两人两间房生成可用结果。浏览器测试使用临时端口、独立数据库和演示接口，不向用户现有行程写入数据，不调用真实模型、地图或票务接口。
