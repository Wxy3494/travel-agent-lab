# 步行导航、简洁展示与酒店分店

连续的步行提示合并成一行，例如1549米与145米显示“步行共1694米”。保留公交、地铁、高铁的先后顺序。新生成路线额外保存高德步行段的起终点；步行链接使用[高德官方URI路径规划](https://lbs.amap.com/api/uri-api/guide/travel/route)的`mode=walk`与`callnative=1`，不携带API密钥。相连的步行段合为一个入口；不相连的步行段在同一行提供各段入口，不把整段公交或跨城行程当成步行。

旧行程不改写，显示时也会合并相邻步行文字。旧版公交分段没有保存步行起终点时，不编造导航坐标；重新生成可补齐。旧版明确为纯步行的路线可使用已保存的起终点生成链接。桌面打开高德路线页，移动端按官方协议尝试调起高德APP；实际手机和内置浏览器的调起结果尚未验收。

页面“费用明细”移除逐条数据来源、原始坐标、查询时间、来源说明按钮、长篇预算假设和重复的待核实列表，只保留费用表与一句价格说明。每日路线的费用、入场和房价参考也缩短提示。闭馆、预约、超预算等实际问题仍保留，内部来源与审计记录继续保存在数据库；导出文档不再附加原始来源清单。

为什么目前费用仍是估算：地图路线费用不是指定日期的购买价；美团渠道返回咨询文字，可能有起价、税费未计、房型金额不一致或分店名称不同。尚未取得可可靠对应入住日期、房型、票种及门店的报价时，不直接覆盖预算。当前已接入酒店咨询查询，不能据此声称所有酒店实时价与库存都已核实。

酒店查询同时提供高德酒店名称、完整地址和坐标。美团使用不同分店名时，要求其返回完整地址，再通过高德搜索核对：品牌、街道门牌、楼层房间保留一致，且只对应唯一高德地点编号、并与当前候选酒店相同，才挂上报价参考并标注地址确认。地址缺失、邻店、楼层不同、多个高德候选等情况继续待确认；分店确认不等于价格或库存核实。

2026-11-01公开只读试查：高德找到指定南宁酒店的唯一记录及地址，美团返回房型价格文字但缺少完整门牌地址，系统没有将另一分店名称的报价自动套用。该样例未确认成功，不能写成分店或房价验收通过。原始证据位于`artifacts/navigation-20261101/identity-live-check.json`，没有调用真实DeepSeek、预订或付款。

回归包括步行坐标及顺序、相连与不相连路段、旧行程、数据库与导出、分店唯一与歧义、完整地址及楼层差异。浏览器使用隔离演示数据验证合并文字和链接弹窗参数，外部高德页面由测试拦截，未冒充手机导航验收。当前完整结果见[验收摘要](ACCEPTANCE.md)。
